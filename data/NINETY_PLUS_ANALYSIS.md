## 7. Recommendations for the 90+ Prediction Model

### Features That Matter Most (by enrichment magnitude)

1. **Genre: Soundtrack/Score** (2.67x) — strongest single feature
2. **Genre: Classical/Instrumental** (2.33x)
3. **Artist familiarity** (1.86x) — songs from artists you know well
4. **Genre: Disco/Funk** (1.71x)
5. **Genre: J-Pop/Anime** (1.46x)

### Features That DON'T Matter (near 1.0x)

1. **Genre: Jazz/Swing** (1.16x) — almost neutral
2. **Genre: K-Pop** (1.11x) — slight enrichment only
3. **Release year** — no decade shows strong enrichment

### What to Exclude

- Mumble rap (tanks genre averages without signal)
- RYM default-90 songs (noisier signal than 91–100)
- Artist-level ratings (title == artist rows)

### Recommended Model Architecture

```
Input features:
  - Genre (one-hot encoded)
  - Artist familiarity score (songs rated by this artist)
  - Is soundtrack/Classical (binary)
  - Is "genuine 90+" (91-100 vs exactly 90)

Target: P(song >= 90)

Validation: 5-fold cross-validation on artist clusters
  (prevent artist leakage — all songs by Lawrence in same fold)
```

### Expected Accuracy

With genre enrichment alone, a simple model should achieve **75–80% AUC** on predicting 90+ vs <90. Adding artist familiarity and the orchestral signal should push it to **80–85%**. Full Spotify audio features (energy, danceability, etc.) would likely add another 5–10%.
